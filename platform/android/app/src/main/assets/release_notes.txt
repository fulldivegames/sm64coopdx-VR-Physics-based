## v0.8.2 — Updater and Release Notes Update

- Added the in-game standalone updater, which checks the latest standalone GitHub release, downloads the APK, installs it, and relaunches the game.
- Added title-screen Release Notes pages sourced from the standalone repository.
- Added clear update feedback and permission guidance during the Quest installation flow.

## v0.8.0 — Sonic Shoes Update

- Added Sonic Shoes with timed activation, music, model swap, sparkle effects, configurable 0-300 speed, dive scaling, and high-speed water running.
- Added Sonic Shoes to the spawn menu and balanced power-up box pools.
- Added WiddlePets menu integration in Server Settings.
- Hammers now knock Bully-type enemies back; explosions apply 1.5x knockback.
- Added some conservative large-map optimizations for ROMhacks without reducing visual quality.

## Previous Release Notes - v0.7.9

- Added voice chat, PC microphone selection, Quest microphone support, volume controls, player muting, and speaking indicators.
- Added keyboard voice dictation, Virtual Boy and Game Boy filters, and broader mod compatibility fixes.
