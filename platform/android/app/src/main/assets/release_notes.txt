## v0.8.9 — Large-Map Performance Update

- Major shared PC VR/Quest rendering optimization: batch vertex uploads while preserving draw order, textures, and render state. Dramatically improved the tested Sonic Adventure DX map on Quest; benefits apply to other maps using the same rendering path and vary by workload.
- Added the first public Big Hands power-up to the special spawn pool, with extended hand-based grabbing, punching, and surface climbing. Increased reach by 1.5x and retained independent hand attachments.
- Tightened nearby-surface grab detection. The first-person body stays hidden after a grab until Mario lands.
- Fixed stale special-move audio handles during session shutdown, addressing a stop-hosting crash.
- Preserved the VR-specific updater and existing controller bindings, normal maps, and filters.

## v0.8.4 — SteamVR and Controller Binding Fixes

- Added reliable SteamVR/OpenXR runtime handoff behavior, including ALVR compatibility through SteamVR, without forcing a particular system runtime.
- PC and Quest now use their matching GitHub release feeds, so PC VR updates resolve to the PC VR repository while Quest updates remain on the standalone repository.
- Added controller-binding capture that waits for the next input, supports remapping, and keeps the right-primary menu A action independent from the gameplay Jump binding.
- Added optional texture-matched normal maps with configurable strength and gloss controls. Normal maps are off by default; PC VR ships with 300% strength and 170% gloss.
- Stabilized PC first-person camera height/recenter calibration and thumbstick-turn lighting state while keeping Quest tracking behavior unchanged.
- Kept Sonic Shoes audio and power-up behavior synchronized across the PC VR and Quest builds.

## v0.8.2 — Standalone Updater Hotfix

- Restored the selectable Quest title-screen update button at the top of the main menu.
- Kept latest standalone-release lookup, APK installation, permission guidance, and automatic relaunch.
- Kept the standalone Release Notes page synchronized with this release.

## v0.8.0 — Sonic Shoes Update

- Added Sonic Shoes with timed activation, music, model swap, sparkle effects, configurable 0-300 speed, dive scaling, and high-speed water running.
- Added Sonic Shoes to the spawn menu and balanced power-up box pools.
- Added WiddlePets menu integration in Server Settings.
- Hammers now knock Bully-type enemies back; explosions apply 1.5x knockback.
- Added some conservative large-map optimizations for ROMhacks without reducing visual quality.
