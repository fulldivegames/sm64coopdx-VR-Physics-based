# SM64 Co-Op DX VR Standalone v0.5.0

This is the first public native Quest/Android release of the current SM64 Co-Op DX VR feature set.

## Simple installation

1. Download `SM64-Co-Op-DX-VR-Quest-v0.5.0.apk` from this release.
2. Connect a Developer-Mode-enabled Quest to SideQuest.
3. Choose **Install APK file from folder** and select the APK.
4. Launch the game from **App Library > Unknown Sources**.
5. On first launch, select your own legally obtained, unmodified Super Mario 64 US `.z64` ROM through the Android file picker.

No PC is required after installation. The APK contains no ROM or Nintendo game assets.

## Highlights

- Native ARM64 OpenXR/OpenGL ES stereo rendering on Quest
- First- and third-person VR cameras with tracked controllers
- Physical punching, grabbing, throwing, dives, crouching, Bowser interaction, and collection gestures
- Physical poles, trees, hangable ceilings, monkey bars, moving poles, and ledge completion
- Head-directed locomotion, swimming, Wing Cap flight, shells, cannons, and pole exits
- Default-on Immersion suite with underwater tint, spatial audio, camera comfort, and cannon guidance
- Quest Render Scale defaults to 80% and supports 10%-100%
- Slightly deeper standalone-only color grading without changing the Brightness setting

## Testing notice

The standalone edition has been tested on **Quest 3 only**. It has **not been tested on Quest 2 at all**. It is not completely tested across every level, multiplayer condition, mod, model pack, ROM hack, or long play session.

See the repository README for the complete SideQuest guide, default controls, every physical gesture, settings, performance guidance, and troubleshooting. PC VR users should use the separate [PC repository](https://github.com/fulldivegames/sm64coopdx-VR).
