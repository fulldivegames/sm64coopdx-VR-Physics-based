SM64 CO-OP DX VR - WINDOWS PLAYER GUIDE
========================================

WHAT YOU NEED

- A 64-bit Windows PC
- A PC VR headset with an active OpenXR runtime
- A standard gamepad
- Your own legally obtained, unmodified Super Mario 64 US ROM
  (the ROM commonly identified as Super Mario 64 (U) [!].z64)

Nintendo ROMs and game assets are not included in this download.
The included OpenXR loader is distributed under the Khronos OpenXR SDK
license, provided in licenses/OpenXR-SDK-LICENSE.txt. Its bundled MinGW runtime
dependencies and their applicable license notices are also provided in the
licenses folder.


FIRST-TIME SETUP

1. Extract the entire ZIP to a normal folder. Do not run the game from
   inside the ZIP.
2. Start your headset software and make sure the OpenXR runtime you want
   to use is active.
3. Connect your gamepad.
4. Launch SM64-Co-Op-DX-VR.exe.
5. The first-launch screen will ask for a ROM. Drag your legally obtained,
   unmodified US .z64 ROM onto the game window.
6. Open Settings > VR, enable VR Mode, and choose Camera Settings.
7. Select Third Person Mode or First Person Mode and adjust its camera
   settings to your preference.

The game remembers the validated ROM in its user-data folder, so it should
not need to be dragged in again on every launch.


VR CAMERA MODES

- Third Person Mode keeps Mario visible and works with the default camera or
  SM64 Co-Op DX's free camera. Camera distance is adjustable.
- First Person Mode hides the local Mario model, uses the headset as Mario's
  forward direction, and supports smooth horizontal turning with the right
  stick. Camera height, field of view, and movement-direction calibration are
  adjustable under Camera Settings.
- Experimental settings include an optional smooth 180-degree camera turn for
  backflips and side flips, plus an opt-in flat-screen first-person mode.
- Performance settings include headset render scale and desktop mirror FPS.
  Lower render scale can improve performance while still filling the headset
  display.

KNOWN ISSUE: The 3D star models currently do not appear on the Star Select
screen in VR. The screen remains usable.


TROUBLESHOOTING

- If Windows SmartScreen appears, confirm that you downloaded the ZIP from
  the official fulldivegames GitHub release page. This community build is
  not currently code-signed.
- If VR does not start, confirm that your headset's OpenXR runtime is active.
- For diagnostic output, open PowerShell in the extracted folder and run:

    .\SM64-Co-Op-DX-VR.exe --console

- Include your headset, OpenXR runtime, GPU, reproduction steps, and the
  console lines beginning with [VR] when reporting a VR problem.
