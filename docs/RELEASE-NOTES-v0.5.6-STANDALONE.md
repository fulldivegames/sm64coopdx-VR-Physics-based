# SM64 Co-Op DX VR Quest Standalone v0.5.6

This release brings the reusable physical-cap, body-transparency, and improved physical Bowser controls to the native Quest build.

## Highlights

- Remove, hold, throw, recover, and physically re-equip Mario's cap with the optional anytime-cap setting.
- Shake the removed cap vigorously with **Shaking Hat Gives Wing Cap** enabled, then place it back on Mario or throw the converted cap into the distance.
- Configure body opacity and smooth look-down transparency without fading the tracked gloves.
- Use one or two hands for physical Bowser control and aim the final native throw with controller swing direction.
- Retains v0.5.5 save/settings storage and can be installed directly over the existing application.

## Install or update

1. Download `SM64-Co-Op-DX-VR-Quest-v0.5.6.apk`.
2. Install it through SideQuest over the existing application. Do not uninstall first if you want to preserve the private ROM, saves, and settings.
3. Launch **SM64 Co-Op DX VR** from **Unknown Sources**.

The APK contains no ROM or Nintendo game assets. Quest 3 is the only standalone headset tested by the project; Quest 2 remains untested.
