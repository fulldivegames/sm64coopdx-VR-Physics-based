# SM64 Co-Op DX VR v0.6.0

v0.6.0 is a major optimization and mod-compatibility release for the physics-based PC VR edition.

## Highlights

- Large renderer batching and redundant state-change reductions, including the distant Chain Chomp/Bob-omb Battlefield performance path.
- General actor, flame, lava, weather/effect, menu, shader-preparation, and startup optimizations.
- Correct HUD opacity across normal HUD elements while keeping the optional FPS counter fully readable.
- Character Selector and multi-character-pack compatibility work with stereoscopic VR menu presentation.
- Improved Lua mod, DynOS pack, palette, character-model, and shader-cache integration.
- Native OpenXR controller suggestions for Meta Touch, Valve Index, HTC Vive, Windows Mixed Reality/Samsung Odyssey, and simple/generic profiles used by runtimes such as SteamVR.
- Continued stability improvements across first person, third person, physical carrying, climbing, caps, Bowser throws, and mod-heavy startup.

The project page now begins with installation, mod setup, controls, and a detailed first-person/physical-interaction tutorial. Third-person gamepad mode remains supported with both the default and free cameras.

The Windows ZIP contains no ROM or Nintendo game assets. Supply your own legally obtained, unmodified Super Mario 64 US ROM on first launch.
