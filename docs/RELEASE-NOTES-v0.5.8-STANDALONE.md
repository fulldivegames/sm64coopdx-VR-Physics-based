# SM64 Co-Op DX VR Quest Standalone v0.5.8

This update restores VR pickup support for heavy rear-grab enemies and improves runtime consistency.

## Changes

- King Bob-omb and Chuckya require both physical hands behind the enemy to pick them up.
- Native dive pickups from behind remain supported.
- A hand holding Mario's cap cannot punch, trigger punch sounds, dive, climb, or grab.
- Faster shader lookup, buffered shader-cache learning, and lower-overhead Quest audio transfers reduce intermittent stalls.

Install this APK directly over the existing application to retain the imported ROM, save data, settings, and mods.
