# SM64 Co-Op DX VR v0.5.0

The v0.5.0 PC release adds the first broad motion-control and physical-climbing milestone to SM64 Co-Op DX VR, alongside VR camera, UI, comfort, interaction, and performance work.

## Install

1. Download `SM64-Co-Op-DX-VR-Windows-v0.5.0.zip` from this release.
2. Extract the complete ZIP into a new writable folder. Do not run it inside the archive.
3. Start the headset software and active OpenXR runtime.
4. Run `SM64-Co-Op-DX-VR.exe`.
5. When prompted, supply your own legally obtained, unmodified Super Mario 64 US `.z64` ROM.
6. Open **Settings > VR**, enable VR, choose a camera mode, and recalibrate while facing forward.

The release contains no ROM or Nintendo game assets. The Windows package includes its OpenXR loader and required runtime libraries.

## Highlights

- Native OpenXR stereo, 6DoF tracking, first- and third-person VR cameras
- Remappable motion-controller input and smooth turning
- Physical punching, grabbing, throwing, dives, crouching, ground pounds, Bowser throws, and cap/collection gestures
- Physical pole, tree, hangable-ceiling, monkey-bar, and hand-over-hand climbing
- Optional climb-any-wall/ceiling cheat, plus safe ledge completion and moving-pole support
- Head-directed walking, swimming, flight, shell riding, cannon aiming, and pole dismounts
- Full-resolution VR menus, HUD controls, desktop mirroring, render scale, and shader preparation
- Default-on Immersion suite, including positional sound, cannon guidance, face-stuck blackout, ledge camera, and underwater filter

See `README.txt` inside the package or the repository README for complete controls, gestures, settings, troubleshooting, and performance guidance.
