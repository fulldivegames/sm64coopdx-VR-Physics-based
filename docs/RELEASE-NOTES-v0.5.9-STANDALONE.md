# SM64 Co-Op DX VR Quest Standalone v0.5.9

This hotfix removes the two-hand requirement for heavy rear-grab enemies.

- King Bob-omb and Chuckya can now be grabbed with either VR hand.
- Physical grabs still require approaching from behind.
- Dive pickup remains supported.
- Adds default-on Flame & Lava Optimizations to reduce transparent overdraw, flame trail actors, lava bubbles, and avoidable per-actor distance work while preserving hazard collision behavior.
- Includes all v0.5.8 performance improvements.
